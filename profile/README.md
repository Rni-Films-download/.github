## 🧠 Overview

RNI Films is a film emulation pack for Lightroom, Camera Raw and mobile: each preset reproduces a specific negative or slide stock, including the colour shift of ageing film and the grain structure of its speed class.

On a Windows machine it runs as a preset pack that loads inside Adobe Lightroom Classic, Adobe Camera Raw. Typical use is film emulation presets work on local files, so the application does not need a subscription or a cloud project to open and save documents.

| Feature | Description |
